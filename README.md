# Ogun River Catchment-to-Coast Environmental Observatory (2019–2024)

**Repository:** `https://github.com/oloyededavid/Ogun-Catchment-Coast-Observatory`  
**Live Interface:** `https://oloyededavid.github.io/Ogun-Catchment-Coast-Observatory/`

An integrated Earth Observation and hydrological research observatory investigating how monthly rainfall variability and shallow surface soil-moisture conditions across the Ogun River catchment relate to seasonal SAR floodplain inundation indicators and downstream estuarine spectral turbidity dynamics (`NDTI`) in the northwest Lagos Lagoon.

> **Data status: Google Earth Engine export (script v2.3.0, 2019-01 to 2024-12).** The files in `docs/data/` are the unedited output of `gee/01_extract_real_ogun_data.js`, installed with `src/01_ingest_gee_exports.py`; `cascade_diagnostics.json` is generated by `src/02_compile_observatory.py`, and the tests check it matches. To refresh the data:
> 1. Run `gee/01_extract_real_ogun_data.js` in the Earth Engine Code Editor. Check the zone counts printed in the console and the Oyan Reservoir layer on the map, then run the three exports (`ogun_subbasins`, `ogun_monthly_timeseries`, `ogun_unit_monthly_timeseries`).
> 2. Download the exports from Google Drive and install them with the ingest script, which validates them and regenerates the diagnostics (see section 5).
> 3. Run the tests, then commit the files in `docs/data/` unedited.

## 1. Research Question & Scientific Scope

**Central Research Question:**  
*How do monthly and seasonal rainfall variability and shallow surface soil-moisture conditions across the Ogun River catchment relate to SAR-detected floodplain inundation indicators and downstream estuarine spectral turbidity dynamics ($\text{NDTI}$) in the northwest Lagos Lagoon?*

### Specific Objectives
1. **Topological Catchment vs. Estuarine Separation:** Delineate the upland hydrological sub-basins of the Ogun River watershed (`WWF HydroBASINS Level 9`, Units `Z1–Z4`) along true watershed divides and separate them topologically from the downstream estuarine receiving water body in the northwest Lagos Lagoon (`Unit Z5`).
2. **Multi-Sensor Environmental Monitoring (2019–2024):** Quantify monthly CHIRPS v2.0 precipitation, ERA5-Land shallow surface soil moisture (`0–7 cm`), topographically conditioned Sentinel-1 SAR low-backscatter inundation proxy areas, and cloud-masked Sentinel-2 open-water spectral turbidity ($\text{NDTI}$).
3. **Statistical Coupling & Autocorrelation Audit:** Evaluate both raw seasonal associations and deseasonalized anomaly associations across lags $\tau \in \{0, 1, 2\}\text{ months}$ while accounting for serial autocorrelation (Bretherton effective sample size $n_{\text{eff}}$), non-normality (Shapiro–Wilk), cloud-masked missing optical months (`NaN`), and multiple testing (Benjamini–Hochberg FDR).

## 2. Study Area & Analytical Units (`EPSG:4326`)
* **Units Z1–Z4 (Hydrological Catchment Sub-Basins):** Intact `WWF/HydroSHEDS/v1/Basins/hybas_9` watershed polygons of the 22,166 km² Ogun catchment, grouped by upstream tracing through the HydroBASINS `NEXT_DOWN` network from fixed level-9 outlet units (Oyan Dam → `Z2`; upper Ogun above the Oyan confluence → `Z1`; lower mainstem at ~6.9°N → `Z3`, minus `Z1` and `Z2`; the reaches below → `Z4`). The Ogun's `MAIN_BAS` is the whole 48,394 km² Lagos Lagoon system (including the Osun basin) and is not used as the catchment:
  - `Z1`: Upper Ogun Headwaters Sub-Basin (`Oyo Basement Complex`)
  - `Z2`: Oyan–Ofiki Tributary Sub-Basin (`Western Regulated Tributary`)
  - `Z3`: Middle Ogun Mainstem Sub-Basin (`Abeokuta–Papalanto–Ifo Corridor`)
  - `Z4`: Lower Ogun Alluvial Corridor (`Mowe–Isheri–Akute–Ikorodu Floodplain`)
* **2 km Riparian Corridor:** Generated by buffering `WWF/HydroSHEDS/v1/FreeFlowingRivers` reaches (`ORD_STRA >= 3`) by `2,000 m` for cloud-free land vegetation (`NDVI`) assessment.
* **Unit Z5 (Northwest Lagos Lagoon Estuarine Receiving Zone):** Topologically disjoint (`difference(catchmentGeom)`) coastal receiving domain (`[3.32°E–3.51°E, 6.45°N–6.58°N]`) where permanent open water (`JRC occurrence >= 50%`, `MNDWI > 0`, `SCL == 6`) is evaluated for spectral turbidity ($\text{NDTI}$).

| **Terrain Slope** | `COPERNICUS/DEM/GLO30` | `30 m` | Terrain slope in degrees; `slope < 5.0°` masks hillslope radar shadow from SAR proxy. |
| **Surface Water** | `JRC/GSW1_4/GlobalSurfaceWater` | `30 m` | `occurrence >= 80%` separated as permanent water; `occurrence >= 50%` masks estuarine water. |

| **Shallow Soil Water** | `ECMWF/ERA5_LAND/MONTHLY_AGGR` | `0.1° (~9 km)` | `volumetric_soil_water_layer_1` (`0–7 cm` surface skin layer, $\text{m}^3/\text{m}^3$). |
| **SAR Inundation Proxy** | `COPERNICUS/S1_GRD`, `MERIT/Hydro/v1_0_1` | `10 m` (`60–120 m` zonal) | `IW`, `VV`, `ASCENDING` pass (the descending track covers only ~5% of the catchment); `50 m` focal-median filter. ## 5. Reproducing the Results

```bash
pip install -r requirements-dev.txt
```

After downloading the three Earth Engine exports from Google Drive:

```bash
python src/01_ingest_gee_exports.py \
    --monthly ~/Downloads/ogun_monthly_timeseries.csv \
    --units ~/Downloads/ogun_subbasins.geojson \
    --unit-monthly ~/Downloads/ogun_unit_monthly_timeseries.csv
```

The ingest script rejects exports with missing months, missing columns, missing zones or physically implausible values, and installs nothing if validation fails. It then regenerates `docs/data/cascade_diagnostics.json`.

To regenerate the diagnostics alone:

```bash
python src/02_compile_observatory.py
```

Run the tests before committing. `tests/test_published_data.py` fails if `cascade_diagnostics.json` does not match what the script produces from the published CSV:

```bash
python -m pytest -q tests
```

## 6. Known Limitations

* **Oyan Dam regulation:** release records are not public. The Sentinel-1 open-water area of the Oyan Reservoir (`oyan_reservoir_km2`) is used as a proxy and partialled out of the rain → inundation association.
* **Non-random NDTI gaps:** cloud-masked months cluster in the wet season (April–October), so SAR → NDTI associations are weighted towards dry-season conditions. Coverage by season is reported in `cascade_diagnostics.json`.
* **Short record:** six years give six values per calendar month for deseasonalising, and serial autocorrelation leaves a small effective sample size.
* **Other turbidity drivers:** tides, dredging, sand mining and Lagos urban runoff are not modelled.
* **No ground validation:** no independent flood extents or gravimetric TSS samples were available, so the SAR and NDTI layers are uncalibrated proxies.
* **SAR flood proxy:** a fixed `VV < -16.5 dB` threshold is dominated in this catchment by dry-season false alarms (burnt savanna and dry ground darken in January–March, mostly in `Z1` and `Z2`). The proxy therefore uses change detection against a dry-season reference plus a height-above-drainage filter, and the catchment series covers the floodplain units `Z3 + Z4` only. Monthly median composites miss short-lived floods, and C-band radar cannot see water under vegetation, so absolute areas are small and should be read as an index.
* **Monthly resolution:** coarser than catchment-to-coast travel times; lags reflect seasonal storage memory, not flood-wave routing.
* **Pour points and reservoir box** in the Earth Engine script are approximate and must be checked on the map before exporting.
